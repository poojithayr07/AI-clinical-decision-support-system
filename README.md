# AI-Powered Clinical Decision Support System

An AI-powered clinical decision support system developed using Python, Scikit-learn, and Streamlit to support disease prediction based on patient-reported symptoms and clinical information.

## Project Overview

This project demonstrates the use of machine learning and clinical data to build a decision-support application.

The system processes patient-reported symptoms and relevant clinical information and uses a trained machine learning model to generate disease predictions. It also incorporates patient history and real-time vital information such as SpO2, heart rate, and temperature.

## Objectives

- Develop a machine learning-based disease prediction system.
- Process and transform patient-reported symptoms using NLP techniques.
- Incorporate clinical features and patient history into the decision-support workflow.
- Provide an interactive interface using Streamlit.
- Explore how machine learning can support clinical decision-making.

## Technologies Used

- Python
- Scikit-learn
- Pandas
- NumPy
- TF-IDF
- Random Forest
- Streamlit
- Jupyter Notebook
- SQLite
